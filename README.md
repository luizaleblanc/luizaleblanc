## Sobre Mim

Engenheira de Software Full-Stack especializada na construção de sistemas distribuídos escaláveis, APIs REST resilientes e aplicações web de nível empresarial. Com uma base sólida em engenharia back-end utilizando o ecossistema Java e tecnologias modernas de front-end, faço a ponte entre requisitos de negócio complexos e experiências de usuário fluidas.

*   **Arquitetura Back-End:** Profunda expertise no desenvolvimento de sistemas de alto desempenho utilizando **Java, Spring Boot, RabbitMQ e MySQL**.
*   **Desenvolvimento Front-End:** Histórico comprovado na criação de interfaces responsivas e dinâmicas com **React, Angular, Node.js e TypeScript**.
*   **Cloud & DevOps:** Experiência prática com infraestrutura em nuvem (**AWS, GCP, Azure**), conteinerização (**Docker, Kubernetes**) e automação de pipelines CI/CD.
*   **Padrões de Engenharia:** Fortemente comprometida com **Arquitetura de Software, Clean Code** e práticas rigorosas de qualidade de código (SonarQube) para garantir a manutenibilidade a longo prazo.
*   **Formação Acadêmica:** Estudante de Ciência da Computação na UNINASSAU (Conclusão prevista para 2028).
